# Nextflow Pipeline for Short Read Assembly and Comparisons
##### nf_assembler_short

A Nextflow pipeline written for use of Skomer HPC @ Cardiff University.

| Tool | Version | Reference |
|------|---------|-----------|
| FastQC | 0.12.1 | [S. Andrews Github](https://github.com/s-andrews/FastQC) |
| FastP | 1.3.7 | [Chen, 2025](https://doi.org/10.1002/imt2.107)  |
| Unicycler | 0.5.1 | [R. R. Wicks Github](https://github.com/rrwick/Unicycler)  |
| Bakta | 0.5.1 | [Schwengers et al., 2021](10.1099/mgen.0.000685) |
| ABRicate | 1.4.0 | [T. Seemann Github](https://github.com/tseemann/abricate) |

| Bandage | 0.9.0 | [R. R. Wicks Github](https://github.com/rrwick/Bandage) |
